# موقع أحمد علي العسقلاني

## الملفات
- index.html : الصفحة الرئيسية
- news.js : قائمة الأخبار (هذا هو الملف الذي ستعدّله دائمًا)
- images/ : الصور

## إضافة خبر جديد
1. ارفع صورة الخبر إلى مجلد images (مثال: images/news-new.jpg).
2. افتح news.js واضغط ✏️، وأضف الخبر في أول القائمة بعد السطر `const NEWS = [`:

  {
    "date": "٠١/١٢/٢٠٢٦",
    "title": "عنوان الخبر",
    "text": ["الفقرة الأولى", "الفقرة الثانية"],
    "image": "images/news-new.jpg",
    "link": { "label": "اقرأ المزيد", "url": "https://..." }
  },

   - image و link اختياريان، احذفهما إن لم تحتجهما.
   - انتبه للفاصلة , بعد القوس } بين كل خبر وآخر.
3. اضغط Commit changes، وسيتحدّث الموقع خلال دقيقة.

## حذف خبر
احذف الكتلة من { إلى } الخاصة به مع الفاصلة بعدها.

## النشر على GitHub Pages
Settings ← Pages ← Branch: main ← Save
